# Edit recorded video with Valmera

Use this workflow when the user wants to edit footage they already have in Valmera.

1. Locate the intended project with Valmera’s project listing and inspection tools. Use the project title or identifier provided by the user. If the footage has yet to be uploaded, point them to Valmera Studio and pick up the edit once the project is available.
2. Inspect the transcript and relevant frames. Use those observations and the user’s brief to locate the edit, then apply it with the tools available from the active Valmera connector.
3. Render and inspect the preview. Identify the actual changes and give the user the rendered preview or its link. For a cutaway or caption revision, check both boundaries and the surrounding footage.
4. When the user requests the final file, export the reviewed edit. Report the returned MP4 link when the export completes.

Request templates and recorded results are in the [Valmera MCP examples](https://github.com/ABO3SKRALMASAOODI/valmera-mcp/blob/main/docs/README.md).
