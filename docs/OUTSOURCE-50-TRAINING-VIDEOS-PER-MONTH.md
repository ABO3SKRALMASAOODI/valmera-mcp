# How to outsource editing for 50 training videos a month

Fifty two-minute lessons require 100 finished minutes a month. If each recording averages five minutes, the editor will also handle 250 raw minutes. A package advertised for 50 videos can still fall short if it caps each final cut at 90 seconds or each source recording at three minutes.

Start with one line for each of the five limits below in your request for a quote. Use a separate line for captions, versions and turnaround.

## Write down what the editor will handle

| Quote limit | Illustrative monthly workload | How to check your own workload |
| --- | ---: | --- |
| Lessons delivered | 50 lessons | Count separately approved lessons. Ask how a second version counts. |
| Total finished duration | 100 minutes | Add the planned runtime of every lesson. |
| Longest finished lesson | 2 minutes | Identify the longest planned final cut. |
| Total source duration | 250 minutes | Add every recording the editor needs to review. Include alternate takes and separate screen recordings where applicable. |
| Longest source recording per lesson | 8 minutes | Check the lesson with the most source footage. Ask whether the vendor caps each uploaded file or all source footage for a lesson. |

The example requires **50 approved MP4s and 50 matching SRT files**. Ask the provider to include both in the quote and confirm whether captions, alternate languages or aspect ratios consume the lesson allowance. Replace the example numbers with the totals from your outline and footage log.

## Test the batch with two real lessons

Use a normal lesson and the longest source recording. Include the style reference, lower-third wording and any must-keep teaching step. Ask the provider to return one preview, accept a consolidated correction and return the corresponding MP4 and SRT. Check that edits preserve the order of the instructions and that the SRT matches the approved cut. Record the time from a ready brief to first preview, then from consolidated notes to final delivery.

For four delivery weeks, agree on 13, 13, 12 and 12 approvals, with a specific review window each week. If the first week includes setup, agree on a different schedule that still adds up to 50. Ask how a missing recording or late approval changes the next handoff.
