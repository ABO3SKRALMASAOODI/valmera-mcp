# Evaluate an AI video editor on two weekly talking-head recordings

A fast first cut can still cost more time every week if it removes meaning or you have to fix the same problem again. Run this test on two recordings from your own series before picking a tool. It covers cleanup, approved B-roll, one revision, and the file you deliver.

## Pick two recordings with a useful difference

Use material you can upload. Keep the template, intended audience and delivery format the same. Put these moments in each excerpt:

| Moment | Recording one | Recording two |
| --- | --- | --- |
| Deliberate pause | A pause before the first example | A pause later in the argument |
| Required wording | A named result and the sentence that limits its scope | A different result and a different qualifier |
| Approved B-roll | An uploaded product shot that proves one action | An approved shot for one action and a sentence with no covering footage |

Record source times before starting. Decide what the title and captions may say about the claim. Write down which destination needs a downloadable MP4 and which, if any, needs an editable timeline.

## Give each editor the same assignment

> Tighten this recording. Keep the pause before the example and the full sentence that qualifies the result. Use my approved product shot over the words I marked. Leave the presenter visible where none of my supplied footage fits. Return to the presenter for the conclusion. Show the first cut and tell me where the supporting shot starts and ends.

On the first preview, check the approved shot at both joins and listen to the pause before the example. Watch the passage at normal speed. Ask for one correction, such as returning to the presenter on the next word, while keeping the surrounding narration and timing. Save the first and revised files separately.

## Repeat the workflow on the second recording

Give the editor the same approved visual direction and a new brief for the different source moments. Review at least the following. The [downloadable comparison worksheet](https://valmera.io/downloads/video-editor-comparison-worksheet.txt) has space to record your own results.

| Check | What to record |
| --- | --- |
| Did the intentional pause survive? | The expected and actual source moments on each timeline |
| Did the cut preserve the claim's scope? | The retained line, caption and any changed wording |
| Did the editor place the correct approved shot? | Which asset appeared, during which words, and what happened when no asset fit |
| Did the requested revision land cleanly? | Time spent reviewing and correcting, plus any unrelated changes found |
| Can you ship the file? | MP4 playback, captions, framing and any branding. If you need a timeline, open it with the original media in your intended app. |

Count the review and correction time for both recordings. Compare the cost of the two approved outputs, including any extra render allowances or manual handoff. A good result on your second recording gives you a better estimate of the work you will repeat every week.
