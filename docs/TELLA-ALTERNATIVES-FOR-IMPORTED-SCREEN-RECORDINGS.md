# Tella alternatives for editing an imported screen-recording MP4

Start with the files you have. A clean screen capture and a separate webcam recording let an editor change the layout. In a finished MP4 with the webcam baked into the picture, the recording has no underlying screen detail where the tile covers the video. If it hides a result viewers need, supply a clean take of that step before you pay for a tool or brief an editor.

## Practice the source-file decision

Open the [offline layer test](examples/screen-capture-layer-test/test-capture-layers.html) on GitHub, choose **Download raw file**, then open the saved HTML in your browser. The finished-picture mode shows the webcam tile already present in the pixels. Switch to **Clean screen and separate camera**, then move the camera up or hide it. The export confirmation and filename become visible. This is a layout simulation using a mock screen.

Next play the [six-second recorded layout examples](KEEP-WEBCAM-OVERLAY-CLEAR-OF-ACTION-RESULTS.md#compare-the-same-six-second-software-demo). They use the same synthetic narration and show the Export click at **00:02.00** and the result at **00:03.40**. The example with a clear camera placement exposes the confirmation for 60 decoded frames. In the covered example, it never appears. The examples were rendered as a controlled test of source visibility.

## Run one paid-workflow trial

Supply the same complete recording to each editor you compare. If you have another take, name which file contains the clean result. Ask for a version that keeps the explanation, the control label and the final confirmation. Then ask for a specific change, such as moving the cutaway back by one sentence while preserving the result and original audio.

> Edit my screen recording into a short walkthrough of the export step. Keep the visible Export button, the click, the confirmation and the filename in order. From 00:03.40, use the matching clean screen take if the webcam covers the result. Preserve the narration. Show a preview, then export the approved 16:9 MP4.

If your only file covers the result, check whether you can record the same step again in a sample workspace. Match the visible state and labels. Use the timing of the original narration as a reference. Check the downloaded MP4 at the intended player width and verify that a new viewer can read the filename without narration.
