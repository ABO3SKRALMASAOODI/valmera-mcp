## Run the same small trial across candidates

Use one approved passage containing a name, a number, a negation or condition, and a difficult layout. Record missing capabilities separately from translation errors. A source documentation claim is not a trial result.

## Hand over the deliverables

| Check | Result or remaining work |
| --- | --- |
| Source transcript checked against recording | |
| Translation reviewed in context; reviewer and date recorded | |
| Names, numbers, negations and qualifications checked | |
| Line breaks and script direction checked in rendered output | |
| Captions checked through the whole final edit | |
| Language selection tested in destination player | |
| No unwanted duplicated burned-in and player captions | |
| Original audio preserved as requested | |
| Video and every subtitle file tied to the same edit version | |
| Final video filename, subtitle filenames and language labels | |

Record the specific files the reviewer approved. Keep rejected drafts distinct so that an older subtitle track is not paired with the latest cut. A completed render does not establish linguistic accuracy, and a linguistically correct subtitle file does not establish a readable rendered video.
