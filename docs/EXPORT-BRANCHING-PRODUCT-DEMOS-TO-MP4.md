# Export a branching product demo as MP4 without losing a buyer path

When your product tour lets viewers pick a path, test each intended path in its own downloaded MP4. A viewer can choose **Reports** or **Team members** in the interactive tour. A video playback has a fixed sequence. Send separate videos to each audience, or make one linear video that explicitly shows both workflows.

## Try the export before buying a demo tool

[Download the branching demo test](examples/product-demo-branch-test.html?raw=1) and open it in a desktop browser with MP4 recording support. Choose **Reports** and create the six-second MP4. The visible ending is **Export ready**. Now choose **Team members** and create another MP4. This time the ending is **Invitation sent**. Compare the two downloads. Each has its own action and result. The example runs locally and uses a synthetic workspace to illustrate the delivery decision.

## Review both deliverables with the vendor

1. Show the starting screen, the action and an unambiguous result for each audience. For a hover tooltip, state which words must be readable and how long the viewer should have to read them.
2. Ask for two distinct, versioned MP4s. Specify where each will play, such as a slide deck, an email link or a video player. Carry any clickable destination through in that delivery surface.
3. Ask for one revision to the Reports version while keeping the approved Team members version. Open the replacement file and record the time when its confirmation first becomes readable.
4. If you also ordered a hosted interactive tour, test each route through its public demo link. Ask a reviewer who missed the briefing to reach the two expected results and confirm that each handoff works with their intended access.
