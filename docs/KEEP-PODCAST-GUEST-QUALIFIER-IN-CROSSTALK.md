# Remove a host interruption without losing the guest’s answer in a podcast clip

When a host talks over the start of a guest’s correction, check whether you have separate microphone tracks. With isolated tracks, lower the host for that moment and keep the guest’s audio. When you only have a combined mix, a mute can erase both voices. If the correction still cannot be understood, keep more of the exchange or choose a different excerpt.

## Listen to three versions of the same exchange

[Download the listening test](examples/podcast-two-track-overlap.html?raw=1) and open it in a browser. The file includes all three downloadable audio examples and runs without a network connection.

A fictional guest says yes to downloading training videos for offline use, then says “Only on company-managed devices.” The host’s aside overlaps the start of that condition. Listen from **4.9 seconds** and switch versions.

| Version | What changed | What to listen for |
| --- | --- | --- |
| Original overlap | Both microphones are audible during the correction. | Can you hear the start of the device condition under the host? |
| Mute both voices | The combined mix is silent from **5.053 s to 6.160 s**. | The first part of the guest’s condition disappears with the interruption. |
| Mute the host only | The host is muted over that same range. The guest track stays at its original level. | The full device condition is audible. |

These are locally mixed examples made from synthetic speech. The three files use the same timing. Before encoding, the guest-only correction matched the guest stem throughout the condition, and the host’s question and guest’s initial answer were unchanged. These measurements describe the listening exercise. Try the same comparison on the MP4 from any editing tool you are evaluating.

## Give an editor a pass condition they can verify

> Keep the complete question and answer, including “Only on company-managed devices.” The host says “Right, thank you” over the start of the condition. With separate tracks, reduce just the host during the overlap and preserve the original guest audio. Keep the clip duration and return the MP4 for review.

Play the final file with the captions muted, then with the sound muted. Ask a reviewer who has never heard the episode which devices qualify. They should be able to answer from the retained speech and the matching captions. Ask the vendor to explain how the result changes if a future episode arrives as a combined mix.
