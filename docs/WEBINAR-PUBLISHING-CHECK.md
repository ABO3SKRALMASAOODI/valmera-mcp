# Webinar replay publishing worksheet

Use this with the [webinar editing guide](WEBINARS.md) after reviewing the full downloaded replay. Copy the blank fields into a private project record. This is a manual handoff worksheet, not an automated publisher or a record of a completed test.

## Identify the approved edit

- Recording/project: [name and ID]
- Reviewed version: [actual version identifier]
- Downloaded filename and duration: [file; duration]
- Full-file review with sound completed: [reviewer; date; result]
- Required correction: [visible change and what must remain]
- Original source range: [start–end]
- Corrected replay range: [start–end]
- Separate clips containing the same source moment: [project/version; clip range]
- Chapters and subtitle files belong to: [exact replay version]

## Decide how each destination changes

| Viewer destination | Hosted media ID | Replace existing or publish new? | Published version confirmed | Check time and reviewer |
| --- | --- | --- | --- | --- |
| [event replay URL] | [ID] | [operation] | [yes / pending / incorrect] | [time; name] |
| [website embed page] | [ID] | [operation or same-media dependency] | [result] | [time; name] |
| [separate channel upload] | [ID] | [operation; any new URL] | [result] | [time; name] |
| [teaser viewer URL] | [ID] | [separate correction] | [result] | [time; name] |

Keep private access links and credentials out of shared copies. Use the intended audience's access level when checking playback.

## Preserve what replacement could affect

- Current platform instructions checked: [URL; date]
- Prior version retained where appropriate: [location]
- Analytics exported before a reset, if applicable: [report location; end time]
- Captions, language tracks, descriptions and comments affected: [expected changes]
- Required material preserved or rebuilt: [location; owner]
- Replacement/publish operation: [time; status or job reference]

## Verify the viewer experience

- [ ] Correct beginning and ending play with sound.
- [ ] The corrected moment is visible at the expected replay time.
- [ ] The spoken qualification and surrounding context remain.
- [ ] Required captions and language tracks are available.
- [ ] Chapters land on the intended sections of this version.
- [ ] The event link and website embed serve the intended media.
- [ ] The access gate behaves as intended for the audience.
- [ ] Calls to action reach the intended destination.
- [ ] Each separate clip has its own reviewed and published result.

## Record follow-up

- Unresolved destination or processing job: [reference; next check]
- Publication completed: [time; evidence]
- Analytics before/after boundary: [time; reset or continuous]
- Replay campaign link: [URL without private credentials]
- Clip campaign link: [distinct URL]
- Results to measure: [qualified visits, trials or registrations; reporting window]
