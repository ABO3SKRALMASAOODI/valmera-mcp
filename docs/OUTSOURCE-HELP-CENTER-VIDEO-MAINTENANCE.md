# Compare services for maintaining a SaaS help-center video library

If a release changes the screens in your help center, audit the whole library and send the affected walkthroughs to your editor. A useful quote states which edits can run in parallel, who checks product accuracy and when the team can publish the last approved replacement. Ask for the revised MP4, captions, a chapter map and the project handoff you need for the next release.

## Quote the affected work after a release

Use screen names or routes to match release notes to video chapters. Prioritize a wrong instruction that blocks setup ahead of a cosmetic change. For each affected entry, mark whether you can replace one section or need to recapture the complete workflow. Record every place the outdated version can play.

Suppose a 12-video library has three broken instructions, two changed visual demonstrations and seven still-correct videos. Start with one broken walkthrough as the pilot. Quote the five affected MP4s, five English caption tracks and two additional-language caption tracks, plus a chapter map for each edit. The publishing team separately needs to verify seven live surfaces if two of the videos are each used in two places. A vendor that quotes only the five MP4s leaves part of the job unpriced.

## Send one request to each shortlisted service

> We maintain 12 help-center videos. This release changes five walkthroughs. We will supply the existing MP4s and project files we have, clean screencasts of the new flow, the old chapter links and the approved step text. Quote five replacement MP4s, five English subtitle files, two additional-language subtitle files and a chapter map per video. Specify the project files we get back. Tell us how many updates can run at once, the draft and approval dates, and separately price any work to replace or verify the seven live copies. Quote the first walkthrough as a pilot.

For the pilot, have the product owner follow the changed task straight from playback. Ask for a correction if any prerequisite, click or confirmation is missing. Then deliver the caption file and chapter map to a separate person and have them verify the revised cut on the actual help page. The [publishing guide and delivery sheet](REFRESH-PUBLISHED-PRODUCT-DEMOS.md) cover what to check after you upload a replacement.

If only a flattened MP4 survives, tell the provider before the quote. Ask which edits require replacing a longer section because old captions or labels are baked into the picture. Decide who supplies the new narration and whether localization starts before or after the master is approved.
