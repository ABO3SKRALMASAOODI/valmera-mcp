# Hire an editor for employee onboarding videos across locations

If HR already has recordings, start with one short lesson that needs a different step at two sites. Ask the editor to deliver both versions, then change one shared line and one site-specific step. A first draft tells you what the edit looks like. The update tells you whether the same vendor can keep a library current.

## Brief two versions of the same lesson

For a worked example, assume a new hire must submit an equipment request. Site A uses a web form. Site B opens the request through a shared kiosk. Both need the same opening and the same explanation of how to check the request status.

| Scene | Send the editor | Review before approval |
| --- | --- | --- |
| Shared opening | Approved narration, demo account footage and current policy wording | Both exports contain the same task, eligibility wording and approved layout. |
| Site A action | Starting screen, actual field labels and the confirmation from the web form | The pointer reaches the correct control and the result stays visible long enough to read. |
| Site B action | Kiosk footage, local labels and the kiosk confirmation | The export contains the Site B steps and shows its own result. A reviewer can follow it on the device employees use. |
| Captions and publishing | Required caption format, languages, target player, due date and one reviewer per site | Captions match each version, names and interface labels are correct, and each export has its own versioned filename. |

Exercise the update. Ask for a correction to the shared opening on both exports and a button label change on Site B only. Have a reviewer from each site watch the new version in the intended player. Record time to **all approved files**, number of corrections, and whether the editor identified every affected export. Ask the vendor to quote new lessons, updates and additional site or language versions against that workload.
