# Compare product demo video editing services for recurring SaaS launches

For two launches a month, ask each editing service to quote the same bundle. Start with two master walkthroughs, four short cutdowns and two updates to older videos. Give the provider the date the cutdowns must be ready and ask when the first draft, approval and delivery each need to happen.

A first-draft window measures the time to one reviewable file. For launch planning, use the time at which the last approved format can be downloaded. If a vendor starts cutdowns after approval, add the time your team needs to review the master and the time the vendor needs to finish the cutdowns.

## Send one brief to every provider

> We ship two features per month. For each feature, we need a 60-second landscape master, a 30-second web cut and a 15-second vertical cut. We also need two existing walkthroughs refreshed this month. We can supply clean screen recordings, approved copy, logos and a style reference. One screen-recorded confirmation step must remain visible in every version. Please state the intake cutoff, first draft date, revision window, final delivery date and which versions can run in parallel.

Use an agreed purchase quote and file list. Specify the aspect ratio, duration, destination, caption format and whether you need editable project files. Supply the actual screen recording and name the state viewers should see at the end. Assign one reviewer to consolidate product and brand feedback.

## Work backward from the launch

For a Thursday launch, suppose the provider confirms that cutdowns begin only after approval and need up to two business days. If everything must be ready by Wednesday afternoon, approve the master by Monday afternoon. If the first cut is Friday and the reviewer is away until Tuesday, ask for an earlier draft or separate the master and short-form release dates.

Track the pilot with these milestones:

| Milestone | Record |
| --- | --- |
| Intake | Time when recordings, assets and brief were accepted |
| First draft | Time when the master was ready to review |
| Revision | Time the team sent feedback, and time it received the next cut |
| Approved master | Exact version ID and approval time |
| Final handoff | Download time for the master, both shorts and any agreed caption or project files |

Use the pilot to answer one question that affects the second release. For instance, request an update to a small panel while preserving the rest of the approved master. Check the same confirmation step in the three playback files. For the vertical clip, check on a phone that the confirmation and its label are readable.
